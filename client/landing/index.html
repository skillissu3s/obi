Scribble outside the lines.

Your notes are plain .md files. Everything you draw lives beside them — sticky notes, arrows, sketches — and moves when the text does.

create an account → get the desktop app

01 canvas

Think beside your words

Everything you draw is anchored to a line of text. Add a paragraph above and the sticky note moves down with it; reword a sentence and the arrow still points at it. The markdown file never changes.

Pen, shapes, highlights

Sketch in the margin, box a paragraph, highlight a phrase — right next to the text it's about.

Arrows that follow the text

Point from a phrase to a note you left yourself. Edit the sentence and the arrow keeps up.

Whole whiteboards

When a margin isn't enough: boards are files too, on their own or embedded in a note.

02 writing

Rendered as you type

No preview pane to keep in sync, and nothing proprietary to export your way out of later.

Plain files

One note, one .md file. Open the same folder in any other editor; nothing is locked in.

Tables, code, maths

They take shape while you write, with the markdown still there the moment you need it.

Links, tags, tasks

Wiki links and backlinks, daily notes, every task in one place, and a graph of how it all connects.

A markdown file seen as a board — headings are lists, task lines are cards. Drag one and the file changes.

03 sharing

Alone, or with other people

The same notes, shared as far as you want them to go.

Live, together

Share a note or a whole workspace. Edits and cursors arrive as they happen.

Publish a link

A read-only page that looks exactly like your note, drawings included, and updates when you edit.

History and trash

Earlier versions are kept as you write; deleted notes wait in the trash.

04 desktop

Works with no connection

Every workspace is a folder you choose — a new one, or one that already holds notes. An Obsidian vault works as it is.

  • Write offline; it catches up when you're back
  • Edits on both sides merge; collisions keep both copies
  • Optional GitHub sync — on save, on a timer, or by hand

05 self-host

One container, one folder

Your notes sit on your own disk as markdown. The database only remembers who you are and what you shared.

services:
  obi:
    image: obi
    environment:
      APP_SECRET: <a long random string>
      PUBLIC_URL: https://notes.example.com
    volumes:
      - obi-data:/data
    ports:
      - "3000:3000"

Start with one note

You can take them all out again whenever you like. They were only ever files.
